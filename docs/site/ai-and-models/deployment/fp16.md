# FP16 Half Precision

FP16 is a possible future Jetson Orin Nano optimization. It stores floating-point values with 16 bits instead of 32, which can reduce memory traffic and improve inference speed on supported hardware.

## SidewalkPilot Status

The live path is FP32 ONNX Runtime with CUDA. SidewalkPilot has not published a measured FP16 latency, power, accuracy, or field result, and no FP16 artifact is the live baseline.

The Series 3 trainer retains an optional `--build-tensorrt --trt-precision fp16` path that invokes `trtexec`. That makes an experiment possible; it does not prove that FP16 is faster or equivalent on the car.

## Required Comparison

An FP16 experiment must use the same model and evaluation set as the FP32 baseline, then report:

- Latency distribution and sustained inference rate on Jetson Orin Nano;
- Bal9, turn exact, turn +/-1, straight exact, MAE, median error, and signed error;
- Memory and power mode; and
- A real-car shadow and turn retest.

Only promote FP16 if the measured benefit matters and the behavior remains acceptable.
