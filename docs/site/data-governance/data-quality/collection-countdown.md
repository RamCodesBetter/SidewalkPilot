# Collection Countdown

An earlier dashboard design showed aggregate photo counters and proposed a per-steering-bucket countdown. Those photo-count pages were removed when the live dashboard was simplified to the single HUB75 layout.

The current 81,237-image dataset is not waiting on a fixed total-count goal. New collection is targeted from a documented field failure, then audited offline for class, lighting, source, and sequence coverage.

A future live collection aid could show current-run class counts, but it is not implemented and should not be described as a current dashboard feature.

See [Turn Coverage](turn-coverage.md) and [Dashboard Pages](../../runtime-code/dashboard/pages.md).
